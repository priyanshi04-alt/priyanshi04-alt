## ⚡ Active Deployments & Missions (Projects)

### 🚨 [Smart Ambulance Traffic Management System](https://github.com/priyanshi04-alt) (Team Lead)
* **Objective:** Real-time emergency vehicle prioritization integrating IoT (ESP32), acoustic sensing, and traffic signals.
* **Stack:** Node.js, Express.js, Socket.io, Leaflet, JWT, ESP32.
* **Actuation:** Achieved ~210 ms end-to-end latency and <25 ms physical signal actuation.

### 🧺 [SmartWash – Smart Hostel Laundry Management System](https://github.com/priyanshi04-alt/Smart_Wash)
* **Objective:** Commercial-grade, full-stack SaaS platform automating laundry lifecycle for large hostels.
* **Stack:** React.js, Node.js, Express.js, Vite, REST APIs, Vanilla CSS.
* **Metrics:** Implemented secure RBAC, a dynamic Weight-Based Limit Engine, real-time tracking timeline, and a Queue & QR Tag count-verification system (0% mismatch rate).

### 👁️ [GazeSense – Eye Movement Analysis](https://github.com/priyanshi04-alt)
* **Objective:** ML pipeline classifying eye-gaze data from YOLO-formatted region annotations.
* **Stack:** Python, Scikit-learn, YOLOv8, SMOTE.
* **Metrics:** Achieved 79.8% test accuracy, 0.781 ROC-AUC using Random Forest. Submitted for conference review.

### 🗺️ [YojnaSetu – Government Scheme Discovery Platform](https://github.com/priyanshi04-alt)
* **Objective:** Eligibility filtering and discovery portal matching schemes with 100% accuracy.
* **Stack:** React 19, Vite 8, React Leaflet, Lucide React, Vercel.
